I/ Security Log Analyzer

Công cụ phân tích file log bảo mật (security.log) bằng Python — đếm số lỗi, 
tìm từ khóa, và kiểm tra IP đáng ngờ.

II/ Tính năng
1. Đếm tổng số dòng chứa "ERROR" trong log
2. Tìm kiếm theo từ khóa bất kỳ trong log
3. Kiểm tra số lần xuất hiện của 1 địa chỉ IP cụ thể

III/ Cách chạy
1. Clone repo này về máy
2. Đảm bảo có file `security.log` cùng thư mục với `main.py`

4. Làm theo menu hiện ra, chọn số 1-4 tương ứng chức năng muốn dùng
